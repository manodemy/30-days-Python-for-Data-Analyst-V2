## 📌 Pinned Comment (Post after uploading)

```
Option A is the trap ❌ | Option B is correct ✅

Why Option A throws an error:
In SQL, WHERE filters individual rows BEFORE GROUP BY runs. Aggregate functions like AVG() don't exist yet at the WHERE stage — they haven't been computed!

Option B correctly uses HAVING, which runs AFTER GROUP BY has computed the average for each department.

💡 Rule of thumb: WHERE = filter rows (before grouping), HAVING = filter groups (after grouping)!

Be honest — did you get this right? 👇
```
